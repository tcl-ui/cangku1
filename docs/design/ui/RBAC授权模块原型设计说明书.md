# 辰光 Agent 平台 — RBAC 授权模块原型设计说明书

> 版本：v1　|　日期：2026-10-25　|　关联需求：[PROJECT_SPEC_V2.md](../../spec/PROJECT_SPEC_V2.md)
>
> 本文档说明「RBAC 授权功能」页面原型的**设计意图、视觉规范、页面结构与交互方式**，供前端实现与评审参考。

---

## 一、概述

本原型为 [PROJECT_SPEC_V2.md](../../spec/PROJECT_SPEC_V2.md) 第六章「前端设计」的可视化落地，覆盖 RBAC 授权在 UI 层的关键表现：

1. **登录后按角色加载权限**（登录页 → 主界面）；
2. **菜单级控制**（侧边栏按权限显隐）；
3. **按钮级控制**（列表页操作按钮按权限显隐）；
4. **角色-权限分配**（角色管理页的权限树）；
5. **权限目录**（权限管理页）；
6. **无权限兜底**（403 页）。

原型定位为**静态高保真演示**，用「身份切换」控件模拟不同权限账号下的界面差异，直观说明 RBAC 授权效果。

## 二、设计目标与原则

### 2.1 目标

- **一致性**：严格复用平台既有视觉语言（`docs/ui/v1–v9`），让 RBAC 原型读起来是「辰光 Agent 平台」的同一套系统，而非另起炉灶。
- **可读性**：权限码、模块、角色等 RBAC 概念在界面上清晰可辨、易于扫描。
- **可演示**：无需后端即可展示「不同身份看到不同界面」的授权效果。

### 2.2 原则

1. **沿用产品外观，只做一处记忆点**：产品壳（深色侧边栏 + 蓝色主色 + 白卡片）保持不变；把视觉重心放在「权限树」与「身份切换」上，不做多余装饰。
2. **权限码用等宽字体**：`user:list`、`role:assign_permissions` 这类标识符本质是代码，用等宽字体既准确又形成视觉层级。
3. **模块用颜色区分**：12 个业务模块各配一个徽标色，帮助在长列表中快速定位。
4. **权限是"被授予的能力"，用紫色标识**：在蓝色产品主色之外，引入紫色 `#7C3AED` 作为 RBAC 子标识，仅用于权限码、403 页、保存分配等「权限」语义场景，避免喧宾夺主。

## 三、视觉规范（Design Tokens）

### 3.1 色彩

**继承平台令牌（不变）**

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sidebar-dark` | `#0F172A` | 侧边栏背景 |
| `--sidebar-text` | `#CBD5E1` | 侧边栏文字 |
| `--main-bg` | `#F1F5F9` | 内容区背景 |
| `--card` | `#FFFFFF` | 卡片/表格背景 |
| `--border` | `#E2E8F0` | 边框/分隔线 |
| `--text` / `--text-muted` | `#1E293B` / `#64748B` | 主/次文字 |
| `--accent` | `#2563EB` | 主操作/激活态 |

**新增 RBAC 子标识**

| 令牌 | 值 | 用途 |
|---|---|---|
| `--violet` | `#7C3AED` | 权限语义（权限码、保存分配、403、切换控件激活态） |
| `--violet-light` | `#EDE9FE` | 紫色浅底（权限码徽标、403 图形） |

**语义色**：`--success #10B981`、`--warning #F59E0B`、`--danger #EF4444`（状态徽标）。

**模块徽标色（12 类）**：用户=蓝、角色=紫、权限=粉、Agent=绿、模型=琥珀、Prompt=青、知识库=天蓝、工具=橙、对话=青绿、统计=靛、工作台=灰、供应商=琥珀。

### 3.2 字体

- **正文/界面**：系统字体栈 `-apple-system, "Segoe UI", Roboto, "PingFang SC", "Microsoft YaHei", sans-serif`（与平台一致）。
- **权限码/代码**：`"SF Mono", "Cascadia Code", Consolas, monospace`，用于 `user:list` 等标识符、403 的 `403 · FORBIDDEN` 标签、验证码字符。
- **字号层级**：页面标题 24 / 卡片标题 16 / 正文 14 / 辅助 12–13 / 权限码 12.5–13。

### 3.3 圆角与间距

- 圆角：`lg 8px`（卡片）、`md 6px`（按钮/输入）、`sm 4px`（分页）、`999px`（切换控件/胶囊）。
- 内容区留白 24px，表格行内边距 12px×20px，卡片内边距 16–20px。

## 四、布局结构

### 4.1 应用外壳（登录后页面共用）

```
┌────────────┬──────────────────────────────────────────┐
│  深色侧边栏  │  顶栏（面包屑 ······ 身份切换控件）        │
│  240px     ├──────────────────────────────────────────┤
│  · Logo    │                                          │
│  · 导航菜单  │   内容区（浅灰底，最大宽 1200 居中）        │
│  · 用户信息  │                                          │
└────────────┴──────────────────────────────────────────┘
```

- **侧边栏**：240px 深色（`#0F172A`），分组导航；当前页高亮为蓝色。菜单项携带 `data-perm`，无权限时整项隐藏；分组下无可见子项时隐藏分组标题（如访客看不到「系统管理」）。
- **顶栏**：面包屑 + 右侧「演示身份」分段控件。
- **内容区**：页面标题/副标题 → 可选紫色提示条 → 统计卡 / 表格卡 / 双栏。

### 4.2 角色管理（双栏特例）

```
┌────────────┬─────────────────────────────────────┐
│ 角色列表    │  选中角色详情                         │
│ (300px)   │  ┌─ 角色名/描述 ──────────────────┐  │
│ · 超管 67  │  │  权限树（按模块分组，可折叠）      │  │
│ · 运营 56  │  │  └ 复选框 + 权限码 + 名称         │  │
│ · 访客 21  │  └────────────────────────────────┘  │
│ · 知编 9   │   [已选 N 项 ······ 保存分配]  ← 吸底  │
└────────────┴─────────────────────────────────────┘
```

权限树为本原型的**视觉重心**：按模块分组、组头可折叠、复选框打勾 + 等宽权限码 + 中文名称，底部吸底「保存分配」栏实时显示已选数量。

## 五、页面说明

### 5.1 登录页（`login.html`）

深色渐变底（slate→indigo）+ 白色卡片；用户名/密码/验证码（含随机字符 `A3BX`）；登录按钮。副文案点明「登录后将按角色加载权限」。

### 5.2 工作台（`dashboard.html`）

页面头 + 紫色提示条（说明身份切换）+ 4 个统计卡 + 「当前身份与权限」摘要卡。摘要卡随身份切换动态变化：超管显示「拥有全部权限」，访客显示「N 项只读权限」。

### 5.3 用户管理（`users.html`）

表格式列表（用户/邮箱/角色/状态/时间），行操作「分配角色 / 编辑 / 删除」。包含两个模态框：**新建用户**、**分配角色**（胶囊式多选）。所有操作按钮挂 `data-perm`（`user:create/update/delete/assign_roles`）。

### 5.4 角色管理（`roles.html`）

左侧角色列表（4 个内置/示例角色，显示权限数），右侧权限树。点击角色即加载其权限；勾选后底部计数实时更新。「新建角色」挂 `role:create`，「保存分配」挂 `role:assign_permissions`。

### 5.5 权限管理（`permissions.html`）

权限码目录表：模块徽标（色块）+ 等宽权限码 + 中文名称 + 行操作。数据由 `rbac.js` 的权限目录渲染，共 67 项、覆盖 12 个模块，与 PRD 4.2 一致。行操作挂 `permission:update/delete`。

### 5.6 无权访问页（`403.html`）

独立页面：锁形图形 + `403 · FORBIDDEN` 等宽标签 + 「无权访问」标题 + 引导文案（含权限码示例 `user:list`）+ 「返回工作台 / 切换账号」按钮。紫色系，情绪克制、指向明确。

## 六、RBAC 授权可视化方案

原型通过三类机制展示「授权」在 UI 层的表现：

| 层级 | 实现 | 演示效果 |
|---|---|---|
| 菜单级 | 侧边栏 `nav-item` 挂 `data-perm`，无权限隐藏 | 访客看不到「系统管理」分组 |
| 按钮级 | 操作按钮挂 `data-perm`，无权限隐藏 | 访客看不到「新建/编辑/删除/分配」按钮 |
| 路由级 | 403 页 + 说明 | 直接访问无权限路由跳 403 |

**身份切换（核心演示控件）**：顶栏分段控件「超级管理员 / 访客」。
- 超级管理员：`is_superuser=true`，全量菜单与按钮可见；
- 访客（只读）：仅 21 项 `:list`/`:view` 权限，系统管理菜单与全部写操作按钮隐藏。

切换由 `rbac.js` 的 `applyGating()` 统一处理：遍历所有 `[data-perm]` 元素按 `hasPermission()` 显隐，并广播 `rbac:changed` 事件更新用户区与权限摘要。

## 七、技术实现说明（原型层）

- **无框架、无构建**：纯 HTML + CSS + JavaScript，双击 `dashboard.html` 即可离线浏览（图片需经本目录相对路径引用）。
- **共享样式** `rbac.css`：设计令牌 + 外壳/表格/徽标/双栏/模态/403/登录等组件。
- **共享脚本** `rbac.js`：`PERMISSION_GROUPS`（67 项权限目录）、`IDENTITIES`（两种身份）、`ROLES`（角色数据）、`hasPermission()`、`applyGating()`、`renderPermTree()`（权限树渲染）、模态/提示等通用交互。
- **数据与 PRD 对齐**：权限码目录、角色（超级管理员/运营管理员/访客/知识库编辑）、错误语义均取自 PRD 第四、六章。

## 八、评审与后续

- 本原型为**静态演示**，不等同于 React 实现；落地时需按 PRD 第六章映射到 `AuthContext` / `PermissionGuard` / `<Can>` 组件。
- 若需调整视觉（如改用既有 `docs/ui/v9_system.html` 的侧边栏图标风格、或更换 RBAC 子标识色），可直接改 `rbac.css` 的令牌变量，全站生效。
- 数据权限（行级）不在本期范围，后续可在此原型上追加「数据范围」列与筛选演示。
